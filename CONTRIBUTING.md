# Contributing

Thanks for helping. This list values accuracy and safety over size.

## How entries work

- Everything lives in [`data.json`](data.json). The README, `llms.txt` and `report.json` are generated by `node scripts/build.mjs` (add `--offline` to skip the GitHub refresh).
- Each entry: `c` category id, `n` name, `u` official URL, `cost`, optional `f` flags, `d` description.
- Order inside a category matters: best in class first, then the strongest free option, then the rest.

## Bar for inclusion

- You have used or evaluated the tool.
- It is maintained, or it is still the best option and the ⚠️ flag explains the risk.
- The link is the official repository or site. Mirrors, forks of unknown provenance and download aggregators are rejected.

## Safety flags

| Flag | Set it when |
|------|-------------|
| `runs` | The tool executes the target, emulates it, or loads third-party plugins or scripts by design |
| `cloud` | The tool sends binaries, code or decompiled output to a third-party service |
| `impersonated` | Lookalike download sites or trojanised builds of the tool have been publicly reported |

## Out of scope

Tools whose main purpose is cracking licences, bypassing DRM, cheating in online games, or evading security products. Malware sample collections.

## Style

One sentence per description, ending with a period, saying when the tool is the right choice. No em dashes.
